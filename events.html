postMessage

События

Капча общается с вашим сайтом через postMessage. Ваш сайт слушает сообщения, подгоняет высоту окошка и узнаёт, когда проверка пройдена.

От капчи к вашему сайту

Эти сообщения приходят в обработчик window.addEventListener('message', …). У каждого поля есть type.

captcha-resize
Своя высота в пикселях в поле height — чтобы обрезать <iframe> ровно по плашке.
captcha-success
Пользователь прошёл проверку. Поле source равно i-studio. Можно включать кнопку или отправлять форму.

Пример данных:

message.data
{ type: 'captcha-resize', height: 168 }
{ type: 'captcha-success', source: 'i-studio' }

От вашего сайта к капче

Если капча долго грузится, можно попросить у неё высоту повторно — сразу после загрузки окошка. Это необязательно, но полезно, если вы подключаете слушатель позже.

captcha-height-request
Отправляется в окошко капчи. В ответ придёт captcha-resize с актуальной высотой.
JavaScript
cap.addEventListener('load', function () {
  cap.contentWindow.postMessage(
    { type: 'captcha-height-request' },
    'https://doinwor.github.io'
  );
});

Полный обработчик

Собираем всё вместе: проверка источника, авто-высота и разблокировка кнопки.

JavaScript
var OK = 'https://doinwor.github.io';

window.addEventListener('message', function (e) {
  if (e.origin !== OK) return;        // чужой источник — игнор
  var d = e.data;
  if (!d || !d.type) return;

  if (d.type === 'captcha-resize') {
    cap.style.height = d.height + 'px';
  }

  if (d.type === 'captcha-success') {
    go.disabled = false;
    // при необходимости: signup.submit();
  }
});
