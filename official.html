Установка

Как вставить на сайт

Три шага. Капча не копируется к вам в код — она остаётся на своём адресе, а вы показываете её через <iframe>.

1 Вставьте окошко с капчей

Задайте ширину через width. Высоту не трогайте — капча пришлёт её сама.

<iframe id="cap"
        src="https://doinwor.github.io/captcha/"
        width="500" height="180"
        style="border:0;background:transparent"
        sandbox="allow-scripts allow-same-origin allow-forms"></iframe>

2 Слушайте сообщения

Когда пользователь пройдёт капчу, она пришлёт captcha-success. Тогда разблокируйте кнопку или отправьте форму.

var EXPECTED = 'https://doinwor.github.io';

window.addEventListener('message', function (e) {
  // обязательно проверяем источник
  if (e.origin !== EXPECTED) return;

  // капча сообщает свою высоту — подгоняем iframe
  if (e.data.type === 'captcha-resize') {
    document.getElementById('cap').style.height = e.data.height + 'px';
  }

  // капча пройдена
  if (e.data.type === 'captcha-success') {
    document.getElementById('go').disabled = false;
  }
});

3 Готово

Капча адаптивная: подстроится под ширину окошка. Цвет, размер и положение задаёт ваша страница — сама плашка нейтральная.

События

Что присылает капча

captcha-resize
Своя высота в пикселях (height) — чтобы обрезать iframe ровно по плашке.
captcha-success
Пользователь прошёл проверку. Можно разблокировать кнопку или отправить форму.
Важно

Заметки

Проверяйте origin

В слушателе сравнивайте e.origin с https://doinwor.github.io, а не со звёздочкой — иначе чужой сайт сможет подделать сигнал.

Google Sites и конструкторы

Некоторые песочницы не пропускают postMessage наружу. Тогда надёжнее держать кнопку «Продолжить» внутри самой капчи.

Полностью клиентская проверка

Сейчас вся проверка идёт в браузере. Для защиты от серьёзных ботов на сервере нужна собственная валидация токена.
