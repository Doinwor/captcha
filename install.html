Установка

Капча не копируется к вам в код — она остаётся на своём адресе https://doinwor.github.io/captcha/, а вы показываете её через <iframe> и ловите сообщение о прохождении. Ниже — что и куда вставлять, по шагам, с готовым примером.

1

Куда вставлять код

Весь код идёт в HTML той страницы, где находится ваша форма или кнопка входа (например signup.html) — внутрь тега <body>, в том месте, где капча должна появиться. Никаких файлов к себе копировать не нужно, только три вставки ниже.

2

Вставьте окошко капчи

Это <iframe> с адресом капчи. Задайте ширину через width (например 500). Высоту не трогайте — капча пришлёт её сама. Атрибут sandbox оставьте как есть: он разрешает капче работать, но изолирует её от вашей страницы.

HTML
<iframe id="cap"
        src="https://doinwor.github.io/captcha/"
        width="500" height="180"
        style="border:0;background:transparent"
        sandbox="allow-scripts allow-same-origin allow-forms"></iframe>
Почему background:transparent

Капча прозрачная: видно только плашку, а фон вашего сайта просвечивает. Если рамка не нужна, ничего больше не добавляйте.

3

Добавьте кнопку

Кнопка, которая должна разблокироваться после прохождения капчи, создаётся с атрибутом disabled — то есть неактивной. Например, это кнопка «Отправить» или «Продолжить».

HTML
<button id="go" type="submit" disabled>Отправить</button>
4

Свяжите кнопку с капчей

Добавьте скрипт до закрывающего </body>. Он слушает сообщения от капчи: подгоняет высоту окошка и включает кнопку, когда проверка пройдена. Обязательно сверяйте e.origin — так чужой сайт не сможет подделать сигнал.

JavaScript
var cap = document.getElementById('cap');
var go  = document.getElementById('go');
var OK  = 'https://doinwor.github.io';   // где живёт капча

window.addEventListener('message', function (e) {
  if (e.origin !== OK) return;            // проверяем источник
  var d = e.data || {};

  if (d.type === 'captcha-resize')        // капча сообщает высоту
    cap.style.height = d.height + 'px';

  if (d.type === 'captcha-success')       // проверка пройдена
    go.disabled = false;
});
Кнопка разблокируется сама

Как только человек пройдёт оба этапа, капча отправит captcha-success, и скрипт снимет disabled — кнопка станет активной. Ничего нажимать вручную не нужно.

5

Полный пример

Скопируйте целиком — это рабочая страница с формой, капчей и кнопкой, которая ждёт прохождения.

signup.html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Форма с капчей</title>
</head>
<body>

  <form id="signup">
    <input type="email" placeholder="Email" required>

    <!-- 1. окошко капчи -->
    <div>
      <iframe id="cap"
              src="https://doinwor.github.io/captcha/"
              width="500" height="180"
              style="border:0;background:transparent"
              sandbox="allow-scripts allow-same-origin allow-forms"></iframe>
    </div>

    <!-- 2. кнопка ждёт прохождения -->
    <button id="go" type="submit" disabled>Отправить</button>
  </form>

  <!-- 3. связать кнопку с капчей -->
  <script>
    (function () {
      var cap = document.getElementById('cap');
      var go  = document.getElementById('go');
      var OK  = 'https://doinwor.github.io';

      window.addEventListener('message', function (e) {
        if (e.origin !== OK) return;
        var d = e.data || {};
        if (d.type === 'captcha-resize' && d.height)
          cap.style.height = d.height + 'px';
        if (d.type === 'captcha-success')
          go.disabled = false;
      });

      // попросить высоту сразу после загрузки капчи
      cap.addEventListener('load', function () {
        cap.contentWindow.postMessage({ type: 'captcha-height-request' }, OK);
      });
    })();
  </script>

</body>
</html>
Если что-то не работает
Кнопка остаётся серой

Проверьте, что e.origin совпадает с https://doinwor.github.io и что скрипт стоит после элементов с id="cap" и id="go".

Окошко слишком высокое

Высота подгоняется сообщением captcha-resize. Обработчик должен быть подключён до загрузки капчи — как в примере выше.

Google Sites и конструкторы

Некоторые песочницы не пропускают postMessage наружу. Тогда надёжнее оставить кнопку внутри самой капчи.
